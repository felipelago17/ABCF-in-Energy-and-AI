# Digests

Machine-generated daily digests from the ABCF monitor
([`scripts/abcf_monitor.py`](../../scripts/abcf_monitor.py)), one file per run:

```
insider-trading/digests/YYYY-MM-DD.md
```

Each digest groups the last 24 hours of activity by classification
(**anti-bribery/corruption**, **insider trading**, **fraud/other**), with, per
item, a 3-bullet summary, a citation link, energy/AI-sector relevance scores,
and flags for extraterritorial reach, a UAE/GCC nexus, insider-trading fact
pattern (**gain-seeking** vs **loss-avoidance**), and any Securities Act
§ 17(a) theory.

> Digest items are **research leads, not findings.** When AI triage is enabled
> every classification is a candidate to be confirmed against the linked primary
> source; when it is disabled the digest lists raw items flagged for manual
> review. High-relevance items also open a GitHub issue labeled `abcf-alert`.
